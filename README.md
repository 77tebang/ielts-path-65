# IELTS PATH · 我的雅思备考室

目标：2026年12月26日Academic机考，总分6.5，单项不低于6.0。

每日任务按实际练习、错因、老师反馈、漏打卡和考试日期调整。普通日核心约4小时30分钟；独立作答、针对错误复盘、再次检验都有明确产出，打卡页面可以直接勾选任务。课程观看与实际输出分开，历史记录保留。

背单词：导入Word后自动按日期分组，支持10.8.2026、10.8、2026-10-08、全角日期及“日期＋课程标题”，以及同段多个英中词条。更新同一Word后重新导入会列出识别日期和新增词数，并直接展示日期列表，原有测验位置与错题记录保留。输入想背的日期或直接点日期卡开始；每轮10词，检查词义和拼写，错词可单独复测。两项均通过才进入后续间隔复习，单次结果不等于永久掌握。重复导入保留进度，识别详情与释义修正在折叠区域。

测验自动保存题目顺序、题号、已答结果和未提交拼写；刷新、退出重进或切换栏目可以继续。打卡、作文和资料输入会自动存为草稿；整轮结束后的结果也会保留。备份包含测验断点、输入和草稿。

背词错题本：词义选择、英文拼写答错或主动选择不记得时自动加入“错题复盘”。按单词累计错误次数并保留最近错答，双项复测通过后标为已纠正，到期再次复习；历史仍可查看。错词复测使用独立断点，不覆盖正常日期测验。旧版可确认的错词自动纳入，具体答案未保存时明确提示。

Word、生词、打卡、作文与复习记录只在当前浏览器保存，不上传GitHub；导出备份包含全部记录，手机电脑不自动同步。默认页面与功能公开，词汇测验不等于官方雅思考试。网站没有独立付费AI服务。

GitHub Pages从main分支根目录发布静态构建文件。
词条检查：导入时整理n./v./adj.等词性标注，完整保留多义项；等号分隔的表达保留为近义关系，不作为拼写题的通用替代答案。英美词典在本机运行，疑似拼写、缺失释义、待核对近义关系暂不出题；用户确认后保留该状态。旧版孤立词性条目排除出题，原有成绩与错题历史仍在备份中。检查不是全面语义或语法批改，专有词与语境释义需人工核对。

第三方拼写词典及组件授权见 THIRD_PARTY_NOTICES.txt。
